# Expense Tracker

**Автор:** <Сартаков Антон>

## Описание

GUI-приложение для учёта личных расходов.

## Возможности

- Добавление расходов (сумма, категория, дата)
- Фильтрация по категории и дате
- Подсчёт суммы за период
- Сохранение в JSON

## Запуск

```bash
pip install tkcalendar
python main.py
